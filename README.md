# Polly Narrator: Terraform Guide

## What is this project

This project will allow the user to give Amazaon Polly some text via a Lambda function and it will turn it into an audio file that will be saved in the auto-generated S3 bucket. The Lambda function will be using the code from the textToSpeech.mjs file which will be uploaded to AWS Lambda using the archive provider.

## Manual Process

Feel free to use the Polly_Narrator.md file to go through the manual process. It also contains extra notes and some final thoughts at the end of the document.

## Steps to run using Terraform

- **Step 1:** Download the repository
- **Step 2:** Open terminal and cd into the root of the repository you downloaded
- **Step 3:** In the terminal type in the folowing command and hit Enter; This will initalize the working directory and download all the necesaary provider plugins and modules
```powershell
terraform init
```
- **Step 4:** After it is done initializing, run the following command and hit Enter
```powershell
terraform apply
```
- **Step 5:** In the terminal you will see all the things that are planned to be built by terraform and at the bottom it will ask if you want to perform these actions. Type *yes* and hit Enter
- **Step 6:** At this point the S3 bucket with an auto-generated name, Lambda function with the textToSpeech.mjs code applied, and all associated IAM roles will have been created
- **Step 7:** From here you will login to your AWS Maagement Console and type in Amazon Lambda; Click on it
- **Step 8:** You will arrive at the Lambda page and should see your function that was created by terraform named TTStranslatorfunction; Click on it
- **Step 9:** This will lead you to the function's Code section; Scroll down a little if needed and you will see the Code Source box
- **Step 10:** You will need to click on the *Create new test event* in the Test Events section of the Code Source box; This should be the bottom left of it
- **Step 11:** A *Create new test event* tab should open and you will give it a name and leave Invocation type. Event sharing, and the template settings as default
- **Step 12:** In the Even JSON box replace the default items between the curly braces with this; Feel free to change the text after the colons, but make sure to leave the quotations
```json
"text":"The text to be converted to Audio"
```
- **Step 12:** Scroll back up to the top of the *Create new test event* tab and click on Save; Close the tab
- **Step 13:** Go to the Test Events section and select the new event you just made and click the blue Test button in the Deply section above the Test Events section
- **Step 14:** This will convert the text into an mp3 file and save it to the auto-generated S3 bucket.
- **Step 15:** Find S3 in your AWS Management Console and click on it
- **Step 16:** You should have arrived at the S3 page and you will click on the bucket that was auto-generated by terraform
- **Step 17:** You should see the mp3 file generated by Amazon Polly; Click on it
- **Step 18:** Clicking on the audio file should have taken you to its properties page
- **Step 19:** Click on the Open button on the rop right and you can listen to it the file in the browser
- **Step 20:** Now return to the terminal and run this command so that everything that was created by the terraform code will be deleted; And just like terraform apply command please type yes at the bottom to confirm the action
  - **Notes: Be sure to confirm in your AWS account that all resources created by terraform have been deleted. My directions should suffice, but please check just in case something doesn't go as planned.**
```powershell
terraform destroy
```
- **Step 21:** With that you have successfully ran the terraform code and created an mp3 file from the text you supplied to Amazon Polly through the AWS Lambda function.
